# Nuxt

Пример приложения [Nuxt](https://nuxt.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/.output/public` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack запускает
`npm run build`, а в нём `nuxt generate`: Nuxt заранее собирает страницы в HTML и кладёт их в
`.output/public`. SPA не нужен — несуществующий адрес отвечает 404.

В демо нет `package-lock.json`: версии пакетов выбираются при сборке по диапазонам из
`package.json`.

Пример с серверным рендерингом — `app-example-nuxt-ssr`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в дев режиме с отслеживанием изменений
npm run dev

# сборка для продакшн с минификацией
npm run build
```

Нужен Node.js 24.15 или новее (в ветке 22 — 22.22.3 или новее).
